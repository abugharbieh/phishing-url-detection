# Phishing URL Detection

This project presents the design, evaluation, and deployment of a machine learning-based system for phishing URL detection using a Random Forest model.

The system leverages lexical feature extraction from URL structures and systematically evaluates the impact of preprocessing techniques and dataset variants on classification performance.

Key components include:
- Feature extraction and engineering from URLs
- Data preprocessing and correlation-based feature selection
- Model training and evaluation using 10-fold cross-validation
- Deployment via a command-line interface and a Streamlit web application for real-time URL analysis

The codebase follows a modular structure, separating preprocessing, feature engineering, training, evaluation, and prediction to support clarity, reproducibility, and maintainability.

Developed as part of a final-year Computer Science with Artificial Intelligence project.
